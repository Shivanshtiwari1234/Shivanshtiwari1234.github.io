Buildzen Studio Documentation

Buildzen Studio is a lightweight browser-based workspace for building, previewing, and testing HTML, CSS, and JavaScript projects in real time.

Overview

Buildzen Studio gives you a small coded environment for making front-end experiences without managing an external toolchain. You can create files, edit them with a code editor, preview the result in a browser-like panel, and inspect console output while iterating quickly.

Build fast

Start from a landing page, portfolio, shop, blog, or SaaS dashboard template.

Preview in context

Test the site at desktop, tablet, and mobile widths before shipping.

Debug in place

Watch logs and errors appear in the Studio console as you work.

Getting Started

  1. Choose Templates in the top bar and select a starter project, or keep the default project.
  2. Confirm template selection to replace the current project, then choose a project file from the left sidebar.
  3. Edit the current file in the code editor.
  4. Use the Refresh button or the keyboard shortcut Ctrl/Cmd + Enter to rebuild the preview.
  5. Use the saved status indicator to confirm your latest work is recorded.

Typical workflow

Most projects start with an index.html file, a style.css stylesheet, and a script.js script. These files are automatically bundled into the live preview so you can see the final result as you code.

Files & Assets

The left sidebar organizes project files and uploaded assets. You can add new files, rename them, delete them, and switch between them without leaving the workspace.

  • HTML: structure and content for your document.
  • CSS: styling and responsive layouts.
  • JavaScript: interactivity, DOM updates, and client-side logic.
  • Assets: upload images, SVG icons, fonts, and supported media into the project asset library. Select an asset to insert a reference in the current file.
  • When a font is inserted into a CSS file, Buildzen creates an @font-face rule using the uploaded filename.

Project storage

Buildzen persists your project inside browser local storage, so your files remain available when you reload the Studio. The save indicator shows when the current files are tracked as saved.

Editor

The editor uses a CodeMirror-based interface with line numbers, syntax highlighting, bracket matching, and selection tools to make writing code easier and clearer.

  • Switch files by clicking them in the project tree.
  • Choose Split to open another project file side by side; edits in either view stay synchronized.
  • Use the status bar to see cursor position and current language.
  • Use search and replace to find patterns rapidly.
  • Apply document formatting for HTML, CSS, and JavaScript content.
  • Expand Blocks in the sidebar to drag or click-insert starter sections into the active HTML file.
  • Expand Components to configure section copy, accent color, and spacing before inserting a reusable section.

Auto-save behavior

The Studio automatically keeps a working copy of your edits and saves when you pause typing. If you leave the page while there are pending changes, the app protects against accidental loss.

Preview

The preview panel acts like a compact browser testing environment. It re-renders the current page, includes responsive device viewports, and supports quick debugging actions.

Device modes

  • Desktop: full-width browser simulation.
  • Tablet: 768px wide viewport.
  • Mobile: 390px wide viewport.
  • Width: enter a custom width from 320px to 1920px to inspect responsive breakpoints as the page updates.
  • Zoom: scale the preview from 50% to 125% without changing its viewport width.

Preview actions

  • Reload: re-renders the current preview.
  • Open: launches the current result in a separate browser tab.
  • Fullscreen: expands the preview area for focused inspection.

Console

The console captures log output from the live project, including warnings and runtime errors. This is useful for debugging front-end behaviour and verifying that scripts are executing as expected.

  • Use the filter buttons to focus on logs, warnings, or errors.
  • Clear the console to remove previous output.
  • Click an error entry to jump to its source area when available.

Export

Use Export in the top bar to download a standalone HTML document with project CSS, JavaScript, and uploaded assets embedded, or a static ZIP containing the project files and assets in an assets/ folder.

Keyboard Shortcuts

  • Ctrl/Cmd + S: save project
  • Ctrl/Cmd + Enter: refresh preview
  • Ctrl/Cmd + F: search within the active file
  • Shift + Alt + F: format the active document
  • Tab: indent selections

Troubleshooting

  • If the preview is stale, refresh the preview or click the Reload button.
  • If an asset does not appear, confirm the file is uploaded and referenced correctly.
  • If a script fails, read the console output and check the relevant file and line.
  • If a change does not seem saved, confirm the Save indicator is in the saved state.

Buildzen Studio is designed to keep the editing and preview loop fast, simple, and close together so you can stay focused on building a working interface.
